# Shopping List App

A simple and interactive Shopping List application built with HTML, CSS, and JavaScript.

## Features

- Add new items to the shopping list
- Edit existing items
- Delete individual items
- Delete all items at once
- Search and filter items
- Store data using Local Storage
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage API

## How It Works

1. Enter an item in the input field.
2. Click the Add button to add it to the list.
3. Edit items whenever needed.
4. Delete a single item or clear the entire list.
5. Use the search box to quickly find items.
6. All data is automatically saved in Local Storage and remains available after refreshing the page.
